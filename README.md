# Custom New Tab

A minimal Chrome extension that replaces the new tab page with a clean, customizable start page.

## Features

- **Bookmarks grid** — add, edit, remove, and drag-and-drop to reorder shortcuts
- **Recently visited** — shows the last 20 unique domains from your history, filtered to exclude already-bookmarked sites; pin any of them to your bookmarks with one click
- **Appearance settings**
  - Background: solid color, preset gradients, or a local image
  - Card style: background color, opacity, and text color
  - Toggle recent history section on/off
  - Restore defaults button
- **i18n** — English (`en_US`) and Portuguese Brazil (`pt_BR`) supported

## Installation

1. Clone or download this repository.
2. Open Chrome and go to `chrome://extensions`.
3. Enable **Developer mode** (top-right toggle).
4. Click **Load unpacked** and select the project folder.
